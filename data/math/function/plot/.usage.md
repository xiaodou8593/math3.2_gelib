# math:plot

绘图器。本模块需要安装math3.1_lalib、iframe1.2

## 绘图器实例

生成绘图器
```
execute anchored eyes positioned ^ ^-3.2 ^10 facing ^ ^ ^-1 run function math:plot/_summon_here
```

销毁绘图器
```
kill @e[tag=math_plot]
```

## 绘图数据

清空绘图数据
```
execute as @e[tag=math_plot] run function math:plot/_clear_coords_as
```

上传绘图数据
```
data modify storage math:io input set value [[1.0d,1.0d],[2.0d,2.0d]]
execute as @e[tag=math_plot] run function math:plot/_upload_coords_as
```
